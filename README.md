# Delivery Bag - Умная термосумка

## Решение проблем с отправкой формы

### Проблема: CORS ошибка при отправке формы

Если у пользователей возникает ошибка CORS при отправке формы, это означает, что Formspree блокирует запросы из-за политики безопасности браузера.

### Решения:

#### 1. Обновленная настройка Formspree
- Добавлен параметр `_captcha: false` для отключения капчи
- Исправлен redirect URL на корректный домен
- Добавлены правильные заголовки CORS

#### 2. Многоуровневая система fallback
Форма теперь использует несколько методов отправки:

1. **Formspree** (основной метод)
2. **PHP скрипт** (fallback)
3. **Mailto ссылка** (последний вариант)

#### 3. PHP Fallback скрипт
Создан файл `send-form.php` который:
- Обрабатывает данные формы
- Отправляет email на `Delivery.Help.me@gmail.com`
- Имеет правильные CORS заголовки
- Валидирует обязательные поля

#### 4. Страница благодарности
Создана страница `thanks.html` для пользователей после успешной отправки формы.

### Настройка сервера

Для работы PHP fallback скрипта убедитесь, что:
- На сервере включен PHP
- Функция `mail()` работает корректно
- Настроены правильные заголовки CORS

### Тестирование

1. Проверьте работу Formspree
2. Протестируйте PHP fallback
3. Убедитесь, что mailto fallback работает

### Мониторинг

Логи ошибок теперь показывают:
- Какой метод отправки использовался
- Детали ошибок для отладки
- Успешные отправки
